# True POS (demo)

An offline-first point-of-sale demo for a liquor shop chain. Four roles (cashier, shop manager, office, owner) run on generated dummy data held in the browser (IndexedDB). There is no backend and no real data.

React 18, Vite, TypeScript, Dexie, and a Workbox service worker (vite-plugin-pwa) for offline use.

## Run it on your computer

```sh
npm i
npm run dev          # http://localhost:5173, for working on the code
npm test             # unit and component tests
```

The offline PWA only works in the built app, because the service worker is not installed by the dev server:

```sh
npm run build
npm run preview      # http://localhost:4173
```

End-to-end checks (Chromium, 1280 x 800). They build nothing themselves, so run `npm run build` first. The first time, install the browser with `npx playwright install chromium`:

```sh
npm run build && npx playwright test
```

The first visit builds the dummy data and takes a few seconds. To start over, open the demo panel (Ctrl+Shift+D, or tap the logo three times) and choose Reset demo data.

## About the data

Every bill, stock count, delivery, member and shop figure is generated by `src/seed/generate.ts` from a fixed seed, so each browser gets the same shops. The only real data in the repository is the product list (name, size, pack and MRP) in `src/seed/catalogue.json`. Do not add real sales, stock or customer data, PDFs or client documents: this repository is public.

Not done yet. The plan is Cloudflare Pages: log in with the right account (`npx wrangler logout && npx wrangler login`), create the project once (`npx wrangler pages project create true-pos --production-branch main`), then `npm run build && npx wrangler pages deploy dist --project-name true-pos`. Open the URL on a tablet, install it as an app, turn the wifi off, and check that billing still works.
